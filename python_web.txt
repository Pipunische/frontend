РАБОТА С ГИТОМ:
git status - просмотреть какие файлы сохранились
git add . - добавить все именения в коробку для отправки
git commit -m "feat(fix,refactor): add visual timer for player turns" - закрыть коробку и подписать 
git push origin main - отправить на личный репо
git push company main:test - на репо компании в main/test
git pull origin main --rebase - скачать изменения из репо
git add clear_main.py - добавить конкретный файл
git add -p clear_main.py - коммитить отдельные строчки!
git add clear_main.py templates/clear_index.html static/css/poker_table.css - пример нескольких файлов
git pull company main - забрать новые
